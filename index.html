Extended VLookup Excel Add-in

An Excel data search tool - No formula, powerful and easy to use

This all-in-one Excel add-in replaces VLOOKUP, XLOOKUP, and INDEX+MATCH formulas with the following special powerful functions :

✓ Multi-condition matching for complex lookups
✓ Fuzzy matching for results containing the keywords
✓ One-to-many results – return all matches or just the first one
✓ Return multiple columns or a continuous column range at once
✓ Search multiple workbooks or an entire folder at once
✓ See exactly where each match comes from: file name, sheet name, and row number
✓ Click to select columns – no need to type column numbers or ranges
✓ Automatically handles merged cells by splitting them during lookup
